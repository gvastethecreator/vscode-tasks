# ADR 0004: Independent implementation

Status: Superceded
Date: 2026-09-03

## Context

Earlier drafts described Status Bar Tasks as an adaptation of another project and packaged a third-party MIT notice.

This product is an independent implementation. Public attribution of another project is not part of the contract.

## Decision

The repository carries only the project MIT `LICENSE`.

There is no `NOTICE` file and no public attribution of another implementation.

## Consequences

VSIX inspection does not require a `NOTICE` file.

README, changelog, and product docs describe this project only.
